ຈັດການສິນຄ້າ

ເພີ່ມ, ແກ້ໄຂ, ຫຼືລຶບສິນຄ້າ — ການປ່ຽນແປງຈະບັນທຶກໄວ້ໃນເຄື່ອງນີ້ທັນທີ ແລະ ສະແດງຢູ່ໜ້າຮ້ານທັນທີ

ສິນຄ້າໝວດໝູ່ລາຄາຈຳນວນໃນສະຕ໊ອກ

ໝວດໝູ່ສິນຄ້າ

ເພີ່ມ, ປ່ຽນຊື່ ຫຼືລຶບໝວດໝູ່ — ໃຊ້ຮ່ວມກັບແບບຟອມເພີ່ມສິນຄ້າ ແລະ ໜ້າຮ້ານ

ໝວດໝູ່ຈຳນວນສິນຄ້າ

ຄຳສັ່ງຊື້

ກວດສອບການຊຳລະ, ເບິ່ງຮູບສະລິບ ແລະ ອັບເດດສະຖານະການສັ່ງຊື້ — ລູກຄ້າຈະເຫັນສະຖານະຜ່ານໜ້າ "ຕິດຕາມການສັ່ງຊື້"

ລະຫັດ / ວັນທີລູກຄ້າການຊຳລະຍອດລວມສະຖານະ

ເຊື່ອມຕໍ່ກັບໜ້າຮ້ານ

ວິທີເຊື່ອມຕໍ່ຂໍ້ມູນລະຫວ່າງໜ້າແອັດມິນ ແລະ ໜ້າຮ້ານ index.html

✅ ວິທີຫຼັກ — ໃຊ້ຮ່ວມກັນອັດຕະໂນມັດ (ແນະນຳ)

ຖ້າເປີດ admin.html ແລະ index.html ຈາກເວັບໄຊດຽວກັນ (domain/origin ດຽວກັນ) ດ້ວຍ browser ດຽວກັນ — ສິນຄ້າ, ໝວດໝູ່, ການຕັ້ງຄ່າ ແລະ ຄຳສັ່ງຊື້ ຈະຖືກອັບເດດແບບ real-time ໂດຍອັດຕະໂນມັດຜ່ານ browser storage, ບໍ່ຕ້ອງເຮັດຫຍັງເພີ່ມ.

⚠️ ຂໍ້ຈຳກັດ: ຂໍ້ມູນນີ້ຢູ່ໃນ browser ຂອງເຄື່ອງ/ຄົນນັ້ນເທົ່ານັ້ນ — ຖ້າລູກຄ້າເປີດຈາກຄົນລະເຄື່ອງ ຫຼືລ້າງ browser data ຈະບໍ່ເຫັນຂໍ້ມູນດຽວກັນ. ສຳລັບຮ້ານທີ່ໃຊ້ຈິງຫຼາຍຄົນພ້ອມກັນ ຄວນເຊື່ອມຕໍ່ backend/ຖານຂໍ້ມູນຈິງ.

① ວິທີສຳຮອງ — ສົ່ງອອກເປັນ CSV ໄປ Google Sheet

ໃຊ້ວິທີນີ້ຖ້າຕ້ອງການໃຫ້ຫຼາຍຄົນອັບເດດສິນຄ້າຜ່ານ Google Sheet ແທນ. ດາວໂຫລດ CSV ແລ້ວນຳໄປວາງໃສ່ Google Sheet, Publish to web ເປັນ CSV ແລ້ວນຳລິ້ງໄປໃສ່ໃນຕົວແປ GOOGLE_SHEET_CSV_URL ໃນໄຟລ໌ index.html

② ວິທີສຳຮອງ — ວາງລົງໄຟລ໌ index.html ໂດຍກົງ

ກັອບປີ້ໂຄ້ດລຸ່ມນີ້ ແລ້ວນຳໄປແທນທີ່ຕົວແປ SAMPLE_PRODUCTS ໃນໄຟລ໌ index.html
